A modern, responsive frontend for a fictional coffee shop built with React 18 and TypeScript. 
This project showcases a clean, inviting design with smooth animations and intuitive navigation.

Built with Vite for lightning-fast development and Chakra UI v3 for elegant, 
accessible components, this application delivers a modern and seamless user experience. 
Developed using React 18 with TypeScript for enhanced scalability and type safety, the platform is fully 
responsive—ensuring accessibility and optimal performance across all devices and media platforms, including mobile, 
tablet, and desktop. Smooth animations, interactive sections, and integrated Google Maps functionality 
create a polished, production-ready interface.

Current features include:

* React 18 with TypeScript for type safety and scalability
* Chakra UI v3 for modern, accessible UI components
* Vite for fast development and optimised builds
* Fully responsive design across mobile, tablet, and desktop
* Smooth animations and transitions
* Google Maps integration for location visibility
* Customer testimonials section
* Interactive menu showcase
