A fully responsive Bootstrap theme built with HTML5 and SCSS, inspired by the HTML5 UP Editorial template. 
I wanted to test my skills and see if I could match the original template while modernising the codebase.

The project features a clean, magazine-style design with a modular SCSS architecture for easy customisation. 
Built with Bootstrap 5, it offers a minimal, organised codebase with modular JavaScript components.

Current features include:

* Clean, magazine-style design
* Fully responsive with Bootstrap
* SCSS architecture for easy customisation
* Minimal, organised codebase
* Modular JavaScript components
* Cross-browser support (Chrome, Firefox, Safari, Edge)
