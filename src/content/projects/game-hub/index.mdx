Game‑Hub Website is a responsive web application built with React, Vite, TypeScript, and Chakra UI that showcases 
a curated collection of video games fetched from the RAWG API. Designed for intuitive browsing and dynamic content display, 
the site emphasizes modern UI/UX and responsive design for desktop and mobile devices. Built as a portfolio/academic project, 
this hub demonstrates practical experience with frontend development, API integration, and modern web tooling.

The website features a clean and modern interface with a focus on usability and aesthetics. Users can explore a wide range of games, 
view detailed information about each title, and navigate seamlessly across different sections of the site. The project highlights 
proficiency in React component architecture, TypeScript type safety, and Chakra UI's design system to create a polished and functional web application.

Current features include:

    * Fetches and displays game data from the RAWG API with pagination support
    * Responsive design using Chakra UI for seamless experience across devices
    * Leverages static typing with TypeScript for improved reliability and developer experience
    * Search functionality to find games by title
    * Detailed game pages with information such as release date, platforms, genres, and ratings
    * Clean and modern UI/UX design focused on usability and aesthetics
