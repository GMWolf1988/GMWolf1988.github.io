# Welcome to my site!

I'm Gareth, a software developer with a background in Games Computing.

This is a little introduction to help you get to know me, what I do and, more importantly, what makes me tick.

First off, I want to apologise for how long it's taken me to write this first post. The website was originally set up at the end of January, but as we all know, life has a habit of getting in the way. Between family life and work commitments, things took a little longer than expected. But now it's time to finally publish that first blog post and welcome you all!

## A little change to the website

If you've visited the site before, you might have noticed a few changes to the layout, theme and overall structure.

When I first launched the site, it was built using vanilla HTML, CSS and JavaScript. Originally, it was only meant to be a place to showcase my work. However, as I started adding more content and features, I realised it would make sense to move to a proper framework.

And that's where <a href="https://astro.build/" target="_blank" rel="noopener noreferrer" class="post-external-link">**Astro**<svg aria-hidden="true" class="h-3 w-3" fill="none" stroke="currentColor" stroke-width="1.8" viewBox="0 0 24 24"><path d="M14 3h7v7m0-7L10 14" /><path d="M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6" /></svg></a> comes in!

Astro is a great fit for what I wanted to achieve. It's lightweight, fast and gives me the flexibility to build a site that focuses on content without adding unnecessary complexity. It also makes managing projects, blog posts and future content much easier, while still allowing me to use the technologies I enjoy working with.

Alongside Astro, I'm also using <a href="https://tailwindcss.com/" target="_blank" rel="noopener noreferrer" class="post-external-link">**Tailwind CSS**<svg aria-hidden="true" class="h-3 w-3" fill="none" stroke="currentColor" stroke-width="1.8" viewBox="0 0 24 24"><path d="M14 3h7v7m0-7L10 14" /><path d="M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6" /></svg></a> for styling. I've found it a great way to keep the design consistent while making it easier to build and adjust layouts. Rather than constantly switching between HTML and separate CSS files, Tailwind lets me apply styling directly where I need it using utility classes. It also makes responsive design much simpler, so I can fine-tune how the site looks across different screen sizes without writing loads of custom CSS.

One other change you might have noticed is that I've removed the theme switcher. After giving it some thought, I decided that a theme control wasn't really necessary for a portfolio website. In my opinion, a portfolio should have a consistent look and feel that represents the person behind it. Keeping one continuous theme helps maintain that visual identity and means less code to manage and maintain. Sometimes, keeping things simple is the better option!

Combining Astro and Tailwind gives me a nice balance of performance, flexibility and maintainability, while making it much easier to develop and expand the site as it grows.

## So, a little about me...

I've been interested in software development from a young age. I made my very first game at 16 using the <a href="https://gamemaker.io/en" target="_blank" rel="noopener noreferrer" class="post-external-link">GameMaker<svg aria-hidden="true" class="h-3 w-3" fill="none" stroke="currentColor" stroke-width="1.8" viewBox="0 0 24 24"><path d="M14 3h7v7m0-7L10 14" /><path d="M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6" /></svg></a> engine. Granted, it was a simple coin-collecting game, but we all have to start somewhere!

In 2007, I went to the University of Lincoln to study Games Design and Production. Unfortunately, I had to leave before completing my degree due to losing my vision. As you can imagine, this hit me pretty hard and affected me both mentally and physically.

But it wasn't all doom and gloom. I picked myself up and, after undergoing operations to regain some of my vision and stabilise my condition, I returned to university in 2021 to give my degree another shot.

Fast forward to 2024, and I graduated with a First!

From university projects to contract work and working with software development companies, I've discovered a real passion for UI/UX design, particularly when it comes to accessibility.

Having my own visual impairment gives me a different perspective on the challenges people can face when using software. It's something I bring into my work, and I genuinely believe that understanding accessibility from personal experience gives me valuable insight into designing better experiences for everyone.
